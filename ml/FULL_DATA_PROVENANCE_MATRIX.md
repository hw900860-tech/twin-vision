## 1. Executive Summary & Verification Classification

Every displayed field across the AERIS-TWIN Ground Control Station (`/gcs`) and Flight Simulator (`/sim`) has been verified by tracing its source code implementation down to its primary input variable.

### Classification Definitions Applied:
- **REAL-DYNAMIC**: Directly controlled or updated by live simulation flight state.
- **PHYSICS-DERIVED**: Calculated via deterministic physics equations in `flightStore.ts`.
- **ML-DERIVED**: Produced by trained Python subsystem models (`ml/models/*.py`) receiving live telemetry features.
- **DERIVED**: Deterministically calculated from current state using mathematical logic (e.g. weighted health fusion).
- **SYNTHETIC**: Demo/simulated baseline values (e.g. static baseline scenarios in read-only demonstrator mode `/gcs`).
- **HARDCODED**: Fixed values not connected to simulation inputs.
- **RANDOM**: Arbitrary values generated by PRNG without physical context.
